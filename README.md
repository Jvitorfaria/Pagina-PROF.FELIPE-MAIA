## Sobre o Projeto

Este projeto consiste no desenvolvimento de uma página web responsiva e acessível para o **Prof. Felipe Maia**, com o objetivo de facilitar o contato de famílias, escolas e pacientes interessados em acompanhamento psicopedagógico e estratégias de inclusão e comunicação acessível na região de Pouso Alegre/MG.

### Áreas de Atuação Apresentadas no Site

* **Psicopedagogia:** Avaliação e intervenção focadas no processo de aprendizagem.
* **Inclusão Escolar e Social:** Orientação e adaptação para promover ambientes inclusivos.
* **Comunicação Acessível:** Recursos e estratégias para ampliar a expressão e compreensão.

---

## Funcionalidades

* **Design Responsivo:** Adaptado para celulares, tablets e computadores.
* **Navegação Intuitiva:** Seções claras e escaneáveis para facilitar a leitura.
* **Contato Direto:** Botões de chamada para ação (CTA) integrados para agendamento rápido.
* **Foco em Acessibilidade:** Contraste adequado e estrutura semântica.
